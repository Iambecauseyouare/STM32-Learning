# 实验名称：按钮控制LED亮灭

## 1.学习目标
- 理解GPIO输入模式
- 掌握 标准 库中 GPIO 的初始化与操作函数
## 2. 硬件准备
- 开发板：STM32F103C8T6
- LED 连接：PA0（低电平点亮）
- 按钮连接：PA1
- 调试工具：CSMIS-DAP
## 3.原理简述
GPIO 是通用输入输出端口，每个引脚可配置为输入、输出、复用、通用等模式。
输出模式下可设置推挽/开漏，输入模式下可设置上下拉和悬空。本实验将PA0配置为通过推挽输出，将PA1配置为输入上拉，通过按钮控制LED的亮灭

## 4.关键代码
```
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;	//	输入上拉
	GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1);   //  获取IO引脚值
```

## 5.问题
按钮竖着插入面包板，LED灯一直亮，原因：**可能是走面包板内部线路短路，导致PA1一直接地，一直亮**。按钮横着插入面包板，则按钮无法控制LED灯亮灭，原因：***可能是面包板线路接触不良*。

## 6.解决方法
用鳄鱼夹将按钮与杜邦线连接在一起之后，可以通过按钮控制LED灯亮灭。
